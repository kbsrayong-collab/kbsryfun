# คู่มือการติดตั้ง Google Apps Script (Code.gs + Index.html)
### ระบบทะเบียนคุมสัญญายืมเงินราชการ (แบบ 8500)

ระบบนี้รองรับการทำงานใน Google Apps Script แบบ 2-in-1:
1. **เป็น REST API ให้กับระบบเว็บ React หลัก**: สำหรับการซิงค์ข้อมูลสองทาง (Pull / Push / Auto-sync)
2. **เป็น Web App อิสระในตัวเอง (Standalone Web App)**: สามารถเปิดผ่านลิงก์ `https://script.google.com/macros/s/.../exec` เพื่อดูทะเบียนคุม บันทึกสัญญา ส่งใช้คืน และพิมพ์เอกสารราชการได้โดยตรง

---

## ไฟล์ในโปรเจกต์ Google Apps Script:
1. **`Code.gs`** (ไฟล์สคริปต์หลัก):
   - เชื่อมต่อและอ่าน/เขียนข้อมูลลงในตาราง Google Sheets แท็บ `ทะเบียนคุมเงินยืม`
   - มีฟังก์ชัน `doGet(e)` และ `doPost(e)` สำหรับ REST API
   - มีฟังก์ชันสำหรับ `google.script.run` ให้กับ `Index.html` ได้แก่:
     - `apiGetContracts()`: ดึงรายการสัญญาทั้งหมด
     - `apiAddContract(contract)`: เพิ่มสัญญาใหม่
     - `apiUpdateContract(contract)`: อัปเดตสัญญาและการส่งใช้คืน
     - `apiDeleteContract(id)`: ลบสัญญา
     - `apiPing()`: ทดสอบการเชื่อมต่อ

2. **`Index.html`** (ไฟล์หน้าเว็บของ Apps Script):
   - อินเทอร์เฟซแบบ Responsive ออกแบบด้วย Tailwind CSS
   - เชื่อมต่อกับ `Code.gs` โดยตรงผ่าน `google.script.run`
   - คำนวณยอดหนี้คงค้าง, วันที่ครบกำหนด, และสถานะค้างชำระเกินกำหนดอัตโนมัติ
   - รองรับการออกหนังสือทวงหนี้ราชการ (บันทึกข้อความ ตราครุฑ)
   - รองรับการพิมพ์ทะเบียนคุมเงินยืมตามแบบ 8500 มาตรฐาน

---

## ขั้นตอนการติดตั้งบน Google Drive (ทำครั้งเดียว):

1. **สร้าง Google Sheets**:
   - ไปที่ [sheets.new](https://sheets.new) เพื่อสร้างสเปรดชีตใหม่ ตั้งชื่อไฟล์ตามต้องการ เช่น `ทะเบียนคุมเงินยืมราชการ`
2. **เปิด Apps Script**:
   - ใน Google Sheets คลิกเมนู **ส่วนขยาย (Extensions)** > **Apps Script**
3. **วางโค้ด Code.gs**:
   - เปิดไฟล์ `Code.gs` ลบโค้ดเดิมทั้งหมด แล้วนำโค้ดจาก `Code.gs` มาวาง
4. **สร้างไฟล์ Index.html**:
   - คลิกเครื่องหมาย **+** ข้างๆ หัวข้อ **ไฟล์ (Files)** ทางด้านซ้าย > เลือก **HTML**
   - พิมพ์ชื่อไฟล์ว่า **`Index`** แล้วกด Enter (Apps Script จะบันทึกเป็น `Index.html`)
   - ลบโค้ดเริ่มต้นออก แล้วนำโค้ดจาก `Index.html` มาวาง
5. **บันทึกโปรเจกต์**:
   - กดปุ่มรูปแผ่นดิสก์ **บันทึกโครงการ (Save project)**
6. **การทำให้ใช้งานได้ (Deploy)**:
   - คลิกปุ่มสีน้ำเงิน **การทำให้ใช้งานได้ (Deploy)** ที่มุมบนขวา > เลือก **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - คลิกไอคอนรูปฟันเฟือง เลือกประเภท **เว็บแอป (Web app)**
   - ตั้งค่า:
     - **คำอธิบาย**: `เวอร์ชัน 1.0 (แบบ 8500)`
     - **ดำเนินการในฐานะ (Execute as)**: `ฉัน (Me)`
     - **ผู้มีสิทธิ์เข้าถึง (Who has access)**: `ทุกคน (Anyone)` *(สำคัญมาก)*
   - คลิก **ทำให้ใช้งานได้ (Deploy)**
   - ให้สิทธิ์การเข้าถึง (Authorize access) ด้วยบัญชี Google ของท่าน
7. **นำ URL ไปใช้งาน**:
   - คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`) นำไปวางในระบบ หรือเปิดใช้งานได้ทันที!
